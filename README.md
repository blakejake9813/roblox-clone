# BrickVerse

A small browser-based Roblox-inspired sandbox prototype built with Three.js.

Features:
- First-person movement with WASD and jumping
- Block placement and removal in a voxel-style world
- Collectible glowing coins
- Simple score and win loop
- Built for quick browser play

## Run it locally

From the project folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Controls

- WASD: move
- Space: jump
- Left click: place block
- Right click: remove block
- Mouse: look around

## Notes

This is a lightweight prototype inspired by Roblox-style building and exploration. It is designed to be easy to extend with more features such as multiplayer, NPCs, inventory, more maps, or a game lobby.
